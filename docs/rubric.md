# Rubrica e aceite

| Unidade | Evidência exigida | Situação inicial |
|---|---|---|
| E0: base externa | Volume pós-limpeza, formato, alvo, dicionário, classes, cobertura e aprovação 1:1 | Candidata auditada; alvo e aprovação pendentes |

| E1: GitHub | README, notebooks, código, dependências e base acessível por reprodução | Estrutura inicial |
| E2: modelagem | Três modelos mais referência, mesma validação e métricas relevantes | Planejado |
| E2: valor | Função de custo, premissas, sensibilidade e plano A/B | Planejado |
| E2: otimização | Optuna sem consultar teste final | Planejado |
| E2: responsabilidade | Explicabilidade, três variáveis, vieses e limites | Planejado |
| Etapa 4 | FastAPI, request, Docker, dependências e API ativa | Planejado |
| Revisões | Relatórios e correções reais, notebooks finais com saídas | Aguardar curso |

Cadência estimada do Caminho 4: semana 1 validação da base; semana 2 Entrega 1; semanas 3–4 modelagem, responsabilidade e deploy. As datas reais dependem das revisões e da disponibilidade de dados. Não antecipar aprovação para caber no cronograma.
